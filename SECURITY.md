# Security policy

## Supported versions

Only the latest release is supported: production runs its images, and fixes land on `main` and ship in the next release.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Report it privately through GitHub's [private vulnerability reporting](https://github.com/krevindiou/bagheera/security/advisories/new) instead.

Include what you can of:

- the affected component (API endpoint, web page, Docker image, workflow),
- steps to reproduce, or a proof of concept,
- the impact you expect.

## Disclosure

You can expect an acknowledgement within 7 days, and an assessment with a planned fix date within 30 days. Fixes ship in a release and are published as a GitHub security advisory once deployed. Please keep the vulnerability private until then; you will be credited in the advisory unless you prefer otherwise.
